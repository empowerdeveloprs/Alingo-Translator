# AlinGo Translate

**A lightweight, offline-first screen translator for Android.**

Translate any text on your screen, lookup words, and hear pronunciations — 
without ads, subscriptions, or privacy violations.

## ✨ Features
- **Screen Translation**: Overlay translations directly on original text.
- **Offline Mode**: 58+ languages available without internet (ML Kit).
- **Word Select**: Long-press the floating button to select and translate any word.
- **Privacy First**: No tracking, no ads, no data collection.
- **Lightweight**: Zero battery drain when idle.
